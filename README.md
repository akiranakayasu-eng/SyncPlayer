# SyncPlayer

10 台ほどの Mac で同じ映像を同期再生するソフト。各 Mac が手元のファイルを再生し、LAN の UDP だけで合わせる。どの Mac もマスターにもフォロワーにもなれる。Mac ごとに映像の変形（位置・大きさ・回転、切り取り、四隅、曲面メッシュ、エッジブレンド）をかけ、プリセットとして保存できる。

## しくみ

1. 時計合わせ: フォロワーがマスターに往復の問い合わせを送り、約 1 分ぶんのうち往復の短い 5 回から「マスターの時計 − 自分の時計」を出す（NTP と同じ考え）。
2. 開始の予約: マスターは「マスターの時計で T に、映像の P 秒から再生」と 0.2 秒おきに知らせる。各 Mac は自分の時計に直して `AVPlayer.setRate(_:time:atHostTime:)` で予約再生する。
3. ずれの直し: 再生はホストの時計で進める（`AVPlayer.sourceClock`）。0.05 秒おきに今の再生位置と予定の位置を比べ、平均で 4 ms を超えたら（1 回でも 40 ms を超えたら）予約し直す。速さの書き換えは AVPlayer が 10 ms ほど止まるので使わない。
4. ループ: 2 つのプレイヤーを交互に使い、次の周を継ぎ目の時刻ちょうどに予約するので、継ぎ目で止まらない。
5. 役の切り替え: M キーでマスターになると、今の再生をそのまま引き継ぐ。前のマスターは新しいマスターの知らせを聞いて自動でフォロワーに戻る（新しくマスターになった方が優先）。
6. 表示: 映像のフレームを Metal で描く。細かい三角形の格子で四隅・曲面メッシュ・位置・大きさ・回転をかけ、切り取りとエッジブレンドと確認用の格子は画素ごとに計算する。同期のタイミングには触れない。

## 使い方

ダブルクリックで使うときは `tools/make-app.sh` で `build/SyncPlayer.app` を作る。起動するとフォロワーになり（M キーでマスターに）、前に使った映像を開く（初めてのときは映像を選ぶ画面が出る）。

```
swift build -c release
.build/release/SyncPlayer --master   movie.mov
.build/release/SyncPlayer --follower movie.mov
```

テスト映像（60fps・20 秒・フレーム番号入り）は `tools/make-test-video.sh` で作る。drawtext の入った ffmpeg が要る（Homebrew の `ffmpeg` には入っていないことがある）。長さは `DUR=150 tools/make-test-video.sh` のように変えられる。

オプション: `--preset 名前`（起動時に読む）、`--fullscreen`、`--screen 1`、`--audio` / `--mute`、`--to 192.168.1.23`（ブロードキャストが通らない LAN で、マスターから知らせを送る先を足す。何度でも）、`--broadcast 192.168.1.255`、`--log`、`--log-interval 0.1`、`--autoplay 2`、`--quit-after 60`、`--switch-after 30`（試験用: 30 秒後に役を切り替える）。

## キー

| キー | 働き |
|---|---|
| space | 再生／停止（マスター） |
| R | 頭へ（マスター） |
| ← → | 5 秒戻る／進む（shift で 1 秒、マスター） |
| M | マスター ⇔ フォロワー |
| S（⌘,） | 設定パネル |
| I / H | 情報の表示／キー一覧 |
| F / D | 全画面／次の画面へ |
| A | 音を出す／消す（標準はマスターだけ音を出す） |
| G | 確認用の格子 |
| E / W | 四隅の変形／曲面メッシュの編集（点をドラッグ、Tab で次の点、矢印で 1 px、shift で 10 px、esc で終える） |
| + − / [ ] | 大きさ／回転（shift で大きく） |
| 0 | 戻す（編集中はその変形、ほかは位置・大きさ・回転） |
| 1〜9 / ⌘1〜⌘9 | プリセット「1」〜「9」の呼び出し／保存 |
| Q（⌘Q） | 終了 |

設定パネルには、役、映像の選択、音、再生の操作、位置・大きさ・回転、切り取り、エッジブレンド（左右上下の幅とガンマ）、四隅とメッシュ（2×2〜8×8）、格子、画面と全画面、名前つきプリセットの保存・読み込み・削除がある。

設定は Mac ごとに `~/Library/Application Support/SyncPlayer/` に保存される（`last.json` が今の設定、`presets/` が名前つきプリセット）。

ポート: UDP 47800（知らせ）、47801（時計）。マスターは 1 台の Mac に 1 つだけ。

## 既知の制限

- ディスプレイの描画タイミングは揃わないので、最大 1 フレームの差は残る。
- 素材はフレーム間圧縮の少ないもの（ProRes、または全フレームがキーの H.264）を推奨。飛び先の読み込みが遅いと予約に間に合わない。HAP は未対応。
- 同じ Mac の上で、マスターが動いたまま別の窓をマスターにすることはできない（ポートが 1 つのため）。
