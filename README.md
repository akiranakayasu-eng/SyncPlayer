# SyncPlayer

10 台ほどの Mac で映像を同期再生するソフト（常設の展示や公演向け）。各 Mac が手元のファイルを再生し、LAN の UDP だけで時間を合わせる。どの Mac もマスターにもフォロワーにもなれる。

v0.3 から、1 台で複数の映像を重ねて出せる。版ごとの違いは [版の履歴](CHANGELOG.md) にある。

- **映像**（クリップ）: そのショーで使う映像ファイル。何本でも足せる。
- **出力**: ディスプレイごとの窓。ノート PC 1 台から、つないだ外部ディスプレイの数だけ（MacBook Air の M1・M2 は外部 1 枚）。全画面にも窓にもできる。
- **レイヤー**: 出力の中に映像を重ねて並べる。レイヤーごとに位置・大きさ・回転、切り取り、四隅、曲面メッシュ、エッジブレンド、不透明度をかける。「4 分割などに並べる」で格子に並べられる。
- **ショー**: 上の全部を 1 つの `.syncshow` ファイルに保存する。ダブルクリックで開ける。

## しくみ

1. 時計合わせ: フォロワーがマスターに往復の問い合わせを送り、約 1 分ぶんのうち往復の短い 5 回から「マスターの時計 − 自分の時計」を出す（NTP と同じ考え）。
2. 開始の予約: マスターは「マスターの時計で T に、映像の P 秒から再生」と 0.2 秒おきに知らせる。各 Mac は自分の時計に直して `AVPlayer.setRate(_:time:atHostTime:)` で予約再生する。
3. ずれの直し: 再生はホストの時計で進める（`AVPlayer.sourceClock`）。0.05 秒おきに今の再生位置と予定の位置を比べ、平均で 4 ms を超えたら（1 回でも 40 ms を超えたら）予約し直す。速さの書き換えは AVPlayer が 10 ms ほど止まるので使わない。
4. ループ: 2 つのプレイヤーを交互に使い、次の周を継ぎ目の時刻ちょうどに予約するので、継ぎ目で止まらない。
   標準は「全部いっしょにループ」。すべての Mac のすべての映像が、いちばん長い映像の尺（または決めた秒数）で同時に頭へ戻る。短い映像は最後のコマで待つ。1 フレームだけ長さの違う映像が混ざっても、頭はそろう。切ると、映像ごとに自分の尺でループする。
   いちばん長い映像の尺は、フォロワーが知らせてくる長さから自動で決まる。長い映像の台が 5 分以上聞こえなくなると、残りの台の長さに縮む。展示では、操作の窓の「長さ」に秒数を入れて固定するのが確実。
5. 役の切り替え: M キーでマスターになると、今の再生をそのまま引き継ぐ。前のマスターは新しいマスターの知らせを聞いて自動でフォロワーに戻る（新しくマスターになった方が優先）。
6. 表示: 映像のフレームを YUV のまま（8 ビット。ProRes 422 は 4:2:2、ProRes 4444 は 4:4:4、ほかは 4:2:0。届かない Mac では次の形に下げる）GPU に渡し、Metal で描く。色の行列は映像の印に従う（印が無ければ 720 ライン未満は BT.601、ほかは BT.709。HDR は明るさを合わせない）。細かい三角形の格子で四隅・曲面メッシュ・位置・大きさ・回転をかけ、切り取りとエッジブレンドと確認用の格子は画素ごとに計算する。同期のタイミングには触れない。

## ダウンロードして使う

1. [Releases](https://github.com/akiranakayasu-eng/sync-player/releases/latest) から `SyncPlayer-<版>-macOS.zip` をダウンロードし、ダブルクリックで展開する。出てきた `SyncPlayer.app` を「アプリケーション」フォルダに入れる（macOS 13 以降、Apple シリコンと Intel の両方で動く）。
2. 初めて開くときだけ、macOS に止められる（Apple の公証を受けていないため）。
   - macOS 15 以降: ダブルクリックして出る画面で「完了」を押す。「システム設定」→「プライバシーとセキュリティ」を開き、下の方の「"SyncPlayer" は開かれませんでした」の横の「このまま開く」を押して、パスワードを入れる。
   - macOS 13・14: `SyncPlayer.app` を右クリック（control キーを押しながらクリック）→「開く」→ 出た画面で「開く」。
3. 「ローカルネットワーク上のデバイスの検出と接続」を求められたら「許可」を押す（Mac 同士で時刻を合わせるのに要る）。新しい版を初めて開く 1 回目は、全画面にする前にダブルクリックで開いてこの許可を済ませておく（全画面の後ろに隠れないように）。
4. 映像を選ぶ画面で、再生する映像を選ぶ（複数選べる）。1 台で M キーを押してマスターにし、space で再生する。
5. 操作の窓で、出力・レイヤー・映像を足したり、出すディスプレイを選んだりする。「保存…」で `.syncshow` にしておくと、次からはそのファイルをダブルクリックするだけで開く。

2 回目からはアプリのダブルクリックだけで開き、前のショーを読む。開いた `.syncshow` には、調整が自動で書き込まれる（初めて書く前の中身は `~/Library/Application Support/SyncPlayer/backups/` に 1 つ控える）。プリセット 1〜9 でショーを入れ替えると、開いていたファイルには書かなくなる。

複数の Mac で使うときの注意:

- Mac ごとに自分のショーのファイルを持つ。1 つの `.syncshow` を同期フォルダに置いて何台もで開くと、各 Mac の調整が同じファイルに書かれて上書きし合う。
- 映像はショーのファイルと同じフォルダに置くと、別の Mac に写してもそのまま開ける（元の場所に映像が無ければ、ショーの隣を探す）。
- ループの設定（全部いっしょ・長さ）はマスターのショーのものが使われる。全台で同じにしておく。
- 全台を同じ版にする。v0.2 の台は共通のループを知らない。
- 版はビルドまで比べる（例「0.3 (77a15b9)」）。Releases の版と手元でビルドした版を混ぜると「版がちがう」と出る。v0.3.2 以前の台は版を送らないので「古い版」と出る。

### サンプル（映像と設定）

[Releases](https://github.com/akiranakayasu-eng/sync-player/releases/latest) の `SyncPlayer-<版>-samples.zip`（v0.3.3 から）は、アプリとは別のダウンロード。展開すると `SyncPlayer-サンプル` フォルダに、音入りのサンプル映像 10 本（1280×720・30fps・20 秒。絵の変わり目と音が同じ瞬間に出るので、何台かのずれを目と耳で確かめられる）、丸いマスクの見本、Runway で作った音のはっきりした 4 秒の映像 5 本、そのままダブルクリックで開けるショー 6 つ（映像 1 本・4 分割・重ねとマスク・台形と切り取り・何台かでそろえる・Runway の映像）と `使い方.txt` が入っている。フォルダの中は名前を変えずに、フォルダごと使う（ショーは同じフォルダの映像とマスクを探す）。何台かで試すときは、全部の Mac にフォルダを写す。映像は `tools/make-samples.sh`（ffmpeg）で作り直せる。

## 使い方

自分でビルドするときは `tools/make-app.sh` で `build/SyncPlayer.app` を作る（`UNIVERSAL=1` で Intel 用も入れる）。配布用の zip は GitHub Actions の release（Actions タブの「Run workflow」で版を入れる）が作って Releases に置く。起動するとフォロワーになり（M キーでマスターに）、前のショーを開く（初めてのときは映像を選ぶ画面が出る）。

```
swift build -c release
.build/release/SyncPlayer --master   movie.mov
.build/release/SyncPlayer --follower movie.mov
.build/release/SyncPlayer --show 展示.syncshow
```

映像を引数に付けると、前のショーの配置のまま映像だけ入れ替える（本数が同じとき）。映像か `--preset` を付けた起動では、ショーのファイルには書かない（試験用）。

テスト映像（60fps・20 秒・フレーム番号入り）は `tools/make-test-video.sh` で作る。drawtext の入った ffmpeg が要る（Homebrew の `ffmpeg` には入っていないことがある）。長さは `DUR=150 tools/make-test-video.sh` のように変えられる。

オプション: `--show ファイル`、`--name 名前`（状態とログに出す名前。標準は Mac の名前）、`--preset 名前`（起動時に読む）、`--fullscreen`、`--screen 1`、`--audio` / `--mute`、`--to 192.168.1.23`（ブロードキャストが通らない LAN で、マスターから知らせを送る先を足す。何度でも）、`--broadcast 192.168.1.255`、`--log`（ずれ・予約し直しの回数・表示したコマ数・飛んだコマ数・描画の fps を 1 行ずつ出す）、`--log-interval 0.1`、`--autoplay 2`、`--quit-after 60`、`--switch-after 30`（試験用: 30 秒後に役を切り替える）。`--bgra`（試験用: コマを以前の BGRA の形で受け取る。標準は YUV のまま GPU に渡して色をシェーダーで変える）。`--frames 420v`（試験用: コマの形を 1 つに決める。`420v`・`422v`・`x422`・`BGRA`）。

## キー

| キー | 働き |
|---|---|
| space | 再生／停止（マスター） |
| R | 頭へ（マスター） |
| ← → | 5 秒戻る／進む（shift で 1 秒、マスター） |
| M | マスター ⇔ フォロワー |
| S（⌘,） | 操作の窓を出す／隠す（全画面の出力の上にも出せる） |
| O / L | 次の出力／次のレイヤーを選ぶ |
| ⌘O / ⌘S | ショーを開く／保存 |
| ⌘Z / ⇧⌘Z | 1 つ前に戻す／やり直す（文字の欄では、その欄の取り消し） |
| N | この Mac の名前・ディスプレイの番号・出力の名前を、出力のまん中に大きく出す／消す（設営のとき、どのディスプレイがどれかを見分ける）。マスターで押すと全台に出る（そのあいだフォロワー側では消せない。展示中にマスターで押すと全台の映像に重なるので注意） |
| I / H | 情報の表示／キー一覧（全画面の出力では、情報は標準で隠れている） |
| F / D | 全画面／次のディスプレイへ |
| A | この Mac で音を出す／消す（ショーに保存され、次の起動でも同じ。決めていなければ `--master` を付けて起動した台だけ音を出す。`--audio` / `--mute` はその起動だけ上書き） |
| G | 確認用の格子 |
| E / W | 選んだレイヤーの四隅の変形／曲面メッシュの編集（点をドラッグ、Tab で次の点、矢印で 1 px、shift で 10 px、esc で終える） |
| + − / [ ] | 選んだレイヤーの大きさ／回転（shift で大きく） |
| 0 | 戻す（編集中はその変形、ほかは位置・大きさ・回転） |
| 1〜9 / ⌘1〜⌘9 | プリセット「1」〜「9」（ショー全体）の呼び出し／保存 |
| Q（⌘Q） | 終了 |

キーは操作の窓と出力の窓で効く（名前の欄に字を打っているあいだは効かない）。

展示のとき: 出力を全画面にすると、その出力には映像だけが出る。マウスの矢印は全画面の出力の上では消え（四隅・メッシュの編集中は出る）、状態の文字は I を押すまで出ない。全画面の出力は操作の窓より手前に出るので、同じ画面にあっても操作の窓は映らない。操作の窓は S で手前に出し、もう一度 S で隠す。全画面の出力はメニューバーと Dock より手前に出るので、どの画面でもそれらは映らない（ショーを開く・保存・画像を選ぶパネルを出しているあいだだけ、全画面の出力を後ろに下げる）。ほかのアプリに切り替えたときや macOS の確認の窓が出たときは、メインの画面の全画面の出力だけ後ろに下がり（その窓が隠れないように）、SyncPlayer に戻ると手前に戻る。ほかの画面の全画面の出力は手前のまま。

再起動のあとも同じ状態に（展示、作者でない人が管理するとき）: 操作の窓の右の「展示の設定」のタブで、Mac ごとに次の 2 つを決めておく。
- 「ログインしたら SyncPlayer を開く」: macOS のログイン項目に入れる（初めてのときは「システム設定 → 一般 → ログイン項目」で許可が要ることがある）。Mac に自動ログインを設定しておくと、電源を入れるだけで開く。
- 「この Mac を展示のマスターにする」: 全台のうち 1 台だけに入れる。入れるとすぐマスターになり、次から開くとマスターで始まって 3 秒後に自動で再生する。この設定は Mac ごとに覚え、ショーのファイルには入らない（ショーをほかの Mac に写してもマスターは増えない）。ほかの Mac は何もしなくてよい（開くとフォロワーになり、マスターに合わせる）。
- 「ログインしたら SyncPlayer を開く」は、SyncPlayer.app を「アプリケーション」フォルダに入れてから入れる（アプリの場所が変わると開かなくなる）。

起動の順番（何台かをまとめて再起動したとき）:
- フォロワーが先に開いた: 止まったままマスターを待つ。マスターが開いて再生を始めると、数秒で時計を合わせて同じ位置から加わる。
- マスターが先に開いた: マスターは 3 秒後に再生を始める。あとから開いたフォロワーは、数秒で時計を合わせて、その時の位置へ飛んで途中から加わる。
- 展示中にマスターだけ再起動した: フォロワーは前の予定のまま再生を続ける。マスターが戻ると、全台がマスターの位置（頭から）にそろい直す。
- **「展示のマスター」は 1 台だけに入れる。** 2 台に入れると、あとから開いた方がマスターになり、全台が頭から再生し直す。
- 設営や点検で、ほかの Mac を M で一時的にマスターにしてもよい。展示のマスターの Mac は次に開いたときにまたマスターになる（そのあいだ、展示のマスターの Mac の状態欄には「ほかの Mac がマスターです」と注意が出る）。
再生中と全画面の出力があるあいだは、画面が暗くなったり Mac が眠ったりしない（アプリが止める）。
ショー（全画面・画面の割り当て・変形・マスク・音）は、開くと前のまま戻る。映像は内蔵のディスクに置く（外付けのディスクは、ログインしたときにまだつながっていないことがあり、そのときは映像を選ぶ画面が出て止まる）。

展示の Mac で設営のときに一度しておくこと（macOS の設定）:
- 自動ログイン（システム設定 → ユーザとグループ。FileVault が入っていると使えない）
- 停電のあと自動で起動（システム設定 → エネルギー、デスクトップの Mac のみ）
- ソフトウェアアップデートの自動インストールを切る（展示中に勝手に再起動しないように）
- 通知を切る（集中モード）
- アプリが落ちたときに自動で開き直す仕組みはまだ無い。落ちたら SyncPlayer をダブルクリックで開き直せば、前の状態に戻る。

マスク: レイヤーに白黒の画像を重ねて、四角以外の形で隠せる（白は見える、黒は隠れる、灰色は半分。「白黒を入れ替える」で逆）。画像は映像の枠全体（切り取りの前）に重なり、レイヤーといっしょに動く・変形する。映像と同じ縦横比の画像を使う（PNG・JPEG など）。画像はショーと同じフォルダに置くと、別の Mac に写してもそのまま使える。画像を描き直して保存すると 2 秒ほどで反映される。透明な所は黒（隠れる）として扱う。写真の向きの情報（スマホで撮った JPEG の回転）は見ないので、向きを直して保存した画像を使う。画像が見つからない・読めないときはマスクなしで映り、操作の窓の状態欄とマスク欄に赤く出る。

音: この Mac で音を出すか（A キー・「この Mac で音を出す」）はショーに保存される。プリセットやショーのファイルを開くと、そのショーの音の設定になる（ほかの Mac に .syncshow を写すと、音の設定もいっしょに写る）。

ショーのファイルを手で書くとき: レイヤーの `corners` などの座標は、出力の左下が 0、右上が 1（y は上向き）。

操作の窓には、上の段に「いまの状態」の札（例「再生中・マスター（…）に合わせている・ずれ 1.2 ms」「マスター待ち」。緑はそろって再生中、灰色は停止中、橙は確かめること。映像が開けない・マスクが読めない・コマが届かない・ずれが大きいときは、状態の言葉のすぐ後ろに ⚠︎ と短い言葉が出て橙になる。マスターと映像の名前がちがうときは、Mac ごとに別の映像を流す使い方もあるので、橙にはせず札の末尾に添えるだけ）・この Mac の役・この Mac で音を出す・ショーを開く／保存、次の段に再生の操作（頭へ・5 秒戻る・再生／停止・5 秒進む。フォロワーでは「マスターの Mac で行う」と出る）・位置のスライダー・「ここへ飛ぶ」（マスターのときだけ出る。分:秒 を打って Return で全台がその位置へ）がある。左に出力（名前・ディスプレイ・全画面にする）、レイヤー（表示・足す・消す・手前へ・奥へ・4 分割などに並べる）、映像（足す・差し替え・外す・全部いっしょにループ・長さ・音を出す映像）。出力・レイヤー・プリセットを消すときと映像を外すときは、確かめの窓が出る（消したレイヤーの調整は戻せない）。まん中にプレビューと「詳しい状態」（境の線を上下に動かして広げられる）。右は 4 つのタブ（手順・画面の調整・展示の設定・プリセット）で、「画面の調整」は選んだレイヤーの設定（映像・不透明度、たたんで開く「位置・大きさ・回転」「切り取り」「マスク」「エッジブレンド」「四隅・曲面」。見出しの文字を押しても開く。E・W で編集に入ると「四隅・曲面」が開く。数字は % と ° で出る）、「展示の設定」はいまのこの Mac の一覧・ログインで開く・展示のマスター・名前と番号（N）・動作確認の文字（I）・困ったときの手順、「プリセット」は名前つきプリセット。右のタブの左端の「手順」は、1 台で動かす → 画面を作る → 何台かでそろえる → 展示の形にする、の 4 段のチェックリスト（できたことにアプリが ✓ を付ける。ショーを保存するまではこのタブで開く）。「練習用のショーを開く」で、番号入りの映像 4 本と丸いマスクの見本をその Mac で作って開く。⌘Z で 1 つ前に戻し、⇧⌘Z でやり直す。各見出しの「?」で使い方のページを開く。「展示の設定」の「点検する」で展示の前の設定をまとめて確かめ、マスターではつながっているフォロワーの名前・ずれ・版・注意が並ぶ。操作の窓の色は「いまのこの Mac」で白・グレー・黒・自動から選べる。

設定は Mac ごとに `~/Library/Application Support/SyncPlayer/` に保存される（`current.syncshow` が今のショー、`presets/` が名前つきプリセット、`backups/` が開いたショーの控え、`current.prev.syncshow` が映像を選び直して新しいショーにしたときの前のショー）。v0.2 の `last.json` と前の映像は、最初の起動で 1 枚目の出力に引き継ぐ。

ポート: UDP 47800（知らせ）、47801（時計）。マスターは 1 台の Mac に 1 つだけ。

## 既知の制限

- ディスプレイの描画タイミングは揃わないので、最大 1 フレームの差は残る。
- 素材はフレーム間圧縮の少ないもの（ProRes、または全フレームがキーの H.264）を推奨。飛び先の読み込みが遅いと予約に間に合わない。HAP は未対応。
- ディスプレイは「何番目のディスプレイか」で覚える。つなぐ順が変わると、出力が別のディスプレイに出ることがある。
- フォロワーの詳しい状態と札の末尾には、マスターと映像の名前が違うと知らせが出る。Mac ごとに別の映像を出す使い方では出続けるが、再生には関係しない（札は橙にならない）。
- 同じ Mac の上で、マスターが動いたまま別の窓をマスターにすることはできない（ポートが 1 つのため）。
- ブロードキャストが通らない LAN では、すべての Mac に同じ `--to` の一覧（全台の IP）を渡しておく。どの Mac がマスターになっても、ほかの全台に知らせが届くようにするため。
- 時計のずれの速さ（ドリフト）は推定していない。最長 60 秒前までの往復の短いサンプルを平均するので、時計の進みが違う Mac どうしでは少しずつ差が出て、4 ms を超えると予約し直しで戻す。
- 知らせに認証はない。閉じた LAN（公演や展示の専用ネットワーク）で使う前提で、同じネットワークの誰でも再生を操作できる。
