v0.3.1: 展示向けの直しです。全画面の出力には映像だけが出ます（マウスの矢印・状態の文字・操作の窓・メニューバーが映らない）。レイヤーに白黒の画像のマスクをかけられるようにし、位置を打って全台を一斉に動かす欄と、Mac ごとの音の設定の保存を足しました。同期でつなぐ Mac は全台を同じ版にそろえてください。この版と前の版の違いは [版の履歴（CHANGELOG）](https://github.com/akiranakayasu-eng/sync-player/blob/main/CHANGELOG.md) にあります。

macOS 13 以降、Apple シリコンと Intel の両方で動く SyncPlayer.app です。

**初めて開くとき**: この .app は Apple の公証を受けていないので、最初の 1 回だけ macOS に止められます。開き方は README の「ダウンロードして使う」を見てください。

使い方・キー・既知の制限は [README](https://github.com/akiranakayasu-eng/sync-player#readme) にあります。
