v0.3.3: 学生が独りで学べるようにした版です。右の「手順」タブに 1 台で動かす → 画面を作る → 何台かでそろえる → 展示の形にする の 4 段のチェックリストを置き、できたことにアプリが ✓ を付けます。ダウンロードなしで開ける練習用のショー、⌘Z の取り消し、各見出しの「?」（使い方のページへ）、マスターでつながっている Mac の一覧（名前・版・ずれ）、展示の前の点検、操作の窓の色（白・グレー・黒・自動）を足しました。版のちがう Mac や古い版の Mac がつながっていると、札が橙になります。同期でつなぐ Mac は全台を同じ版にそろえてください。

**サンプル（映像と設定）**: アプリとは別に `SyncPlayer-0.3.3-samples.zip` を置きました。音入りのサンプル映像 20 本と、ダブルクリックで開けるショー 7 つ、`使い方.txt` が入っています。フォルダごと展開して使ってください。

macOS 13 以降、Apple シリコンと Intel の両方で動く SyncPlayer です（展開すると `SyncPlayer <版>.app`）。

**初めて開くとき**: この .app は Apple の公証を受けていないので、最初の 1 回だけ macOS に止められます。開き方は README の「ダウンロードして使う」を見てください。

使い方・キー・既知の制限は [README](https://github.com/akiranakayasu-eng/sync-player#readme) に、この版と前の版の違いは [版の履歴（CHANGELOG）](https://github.com/akiranakayasu-eng/sync-player/blob/main/CHANGELOG.md) にあります。
